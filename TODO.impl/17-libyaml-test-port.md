# TODO.impl/17 — libyaml test-suite port + event differential vs libyaml

Status: pending · Depends: 12, 16 · Layer: `test/port/libyaml` · PLAN.md phase: 1

## Goal

libyaml's own test harnesses running against yeptris, and a differential
engine that proves our compat mode produces the same events libyaml does
— semantics parity, not just self-consistency.

## Deliverables

- `test/port/libyaml/drivers/` — ports of libyaml's `tests/`:
  `run-parser`, `run-loader`, `run-emitter`, `run-dumper` rewritten over
  the compat adapter (12) + public API; `run-scanner` is token-level —
  replaced by an event-level equivalent with the lossy spots documented
  (libyaml's token stream carries facts we deliberately fold into spans;
  the driver prints event-decomposed equivalents instead).
- `test/port/libyaml/snapshots/` — golden event dumps **generated by
  libyaml itself** (one-time, committed): regression-inputs + examples
  corpora; our drivers must reproduce them byte-for-byte in compat mode.
- `tools/yepdiff.c` (dev tool, not shipped): run both libraries on an
  input, diff event streams + error behavior, report classify-equal /
  differ / both-error. Feeds 19's differential fuzzing.
- CI job: snapshot diff on every push — compat regressions are loud.

## Design decisions

- Golden snapshots come from the reference, not from us (self-generated
  goldens only encode our own bugs).
- Documented-divergence register lives in VALIDATION.md beside 16's
  ledger: a snapshot mismatch is a failure unless registered (same
  never-silent gate).
- The drivers build against system libyaml for snapshot *generation*
  mode only; test execution never links libyaml.

## Phases

A. `run-parser` port + snapshot generation + corpus green (the core
   parity signal).
B. `run-emitter`/`run-dumper` ports over 13's emitter; `run-loader`
  (DOM) over 11.
C. `yepdiff` tool + CI job wiring.

## Acceptance

- All four drivers green over the full regression corpus; zero
  unregistered snapshot diffs.
- `yepdiff` clean (classify-equal or registered) on: corpus + 1M
  fuzz-generated inputs (pre-feeding the corpus to 19).
